# Kurir mascot

Round chibi courier. Cream tunic, terracotta sash, dark curly hair, cream envelope. The K lettermark stays the app icon and sidebar mark; this character is the mascot.

Canonical production crop: `00-canonical-closeup.png` (also `/mascot.png` and `site/public/mascot.png`). kurir.io hero uses `06-full-body-cutout.png` as `site/public/mascot-hero.png`.

## Locked traits

Seed every new pose from `00-canonical-closeup.png` via image-to-image. Do not generate the character from text alone.

- Round chibi proportions: big head, short limbs, sandals
- Dark chocolate curly hair
- Big dark eyes, simple smile, rosy cheeks, warm peach skin
- Cream-white tunic
- Terracotta-red sash across the chest and a matching belt
- Cream envelope in hand
- Thick clean outlines, wholesome, not a baby and not a black silhouette
- Background: fired-clay terracotta filling the square, unless the shot is on paper (`01-closeup-paper.png`)
